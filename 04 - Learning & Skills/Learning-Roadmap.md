# Learning Roadmap — Enterprise Agentic AI Engineer

**Specialization:** Enterprise AI Solutions (Agentic + RAG + Security + Azure)  
**Target:** Job-ready in 8 weeks. Compete with senior engineers on day 1.  
**Decision date:** April 4, 2026 — verified against 6,600+ live job postings.

---

## 8-WEEK DEEP SPECIALIZATION PLAN

### Phase 1: Prove It Works (Weeks 1-2) — Evaluation & Testing

**WEEK 1: Systematic Evaluation**
- **Learn:** RAGAS, DeepEval, custom metrics, eval dashboards
- **Build:** Eval suite on Bayan RAG — faithfulness, relevance, correctness
- **Interview line:** *"I evaluate RAG with RAGAS. 0.87 faithfulness, 0.91 relevance."*

**WEEK 2: Testing & CI/CD**
- **Learn:** Pytest deeply — unit tests, integration tests, fixtures, mocking
- **Build:** Pytest suite on Bayan RAG + Ovie AI. GitHub Actions CI on every push
- **Interview line:** *"Every project I ship has automated tests and CI."*

---

### Phase 2: Lock It Down (Weeks 3-4) — Security & Azure

**WEEK 3: LLM Security & Guardrails**
- **Learn:** Prompt injection (direct/indirect/persistent), data leakage, output filtering, PII detection, jailbreak defense
- **Build:** Guardrails layer on Bayan RAG — input sanitization, output filter, PII masking, jailbreak detection
- **Interview line:** *"I defend against prompt injection and data exfiltration."*

**WEEK 4: Azure Deployment**
- **Learn:** Azure OpenAI Service, Azure AI Foundry, Azure Container Apps
- **Build:** Deploy Bayan RAG or Air-Gapped RAG to Azure with managed endpoints
- **Interview line:** *"I deploy LLM apps on Azure with RBAC and monitoring."*

---

### Phase 3: Think Like An Architect (Weeks 5-6) — System Design

**WEEK 5: System Design Fundamentals**
- **Learn:** Alex Xu vol 1+2. Focus: API gateway, load balancing, caching, message queues, microservices, vector DB scaling
- **Build:** Architecture docs + diagrams for Bayan RAG, Air-Gapped RAG, Ovie AI
- **Interview line:** *"Here's my RAG system for 10K users with caching and LB."*

**WEEK 6: Enterprise Patterns**
- **Learn:** Multi-tenant RAG, audit logging, per-document RBAC, compliance concepts (HIPAA, SOC2), data residency
- **Build:** Multi-tenant support + audit logging on one project
- **Interview line:** *"I build multi-tenant RAG with RBAC and audit trails."*

---

### Phase 4: Agentic Depth (Weeks 7-8) — What Gets $200K+

**WEEK 7: Production Agentic Systems**
- **Learn:** ReAct, Plan-and-Execute, tool calling, state machines, error recovery, human-in-the-loop, agent memory
- **Build:** Multi-agent system — orchestrator + specialists + tool calling + state persistence + retry logic + logging + graceful failure
- **Interview line:** *"I build production agents with state machines and HITL."*

**WEEK 8: Polish & Interview Prep**
- **Do:** 10 mock system design interviews. Polish GitHub. Rewrite resume.
- **Result:** 3 projects with eval, tests, CI/CD, security, Azure, arch docs
- **Interview line:** *"Here are 3 production enterprise AI systems. Here's proof."*

---
